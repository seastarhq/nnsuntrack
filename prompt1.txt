Develop a machine learning system that will use the tensorflow-lite to recognize images of the sun, and distinguish them from other bright objects in the frame. Write a python script to generate synthetic images of bright circular or elliptical objects, triangles, squares, rectangles and polygons up to 7 sides. The script will take parameters including the number of images, overall image size, a minimum and maximum size and ellipticity ratio, and the brightness of the sun and background. The script also generates metadata, including the coordinates of the centroid of the bright shape, and a flag to indicate whether or not this shape represents the sun. The centroid can be close to the edge of the frame, so that the sun will be partially cut off. All images that are not circular or elliptical are not sun. Circular and elliptical images are categorized as sun if the size and ellipticity fall within the minimum and maximum. Add noise to the light and dark portions of the images.

Write a python script to train a neural net using keras to recognize the sun and its centroid in an images. The neural net will be trained using using the synthetic data generated by the previous script. The neural net will be run on a raspberry pi 5 using the tensorflow-lite library. If the neural net recognized the object as not-sun, then it need not give an output for the centroid.
